## Descripcion
¿Buscas el backend para tu frontend? CodeCrush es la primera aplicación de matchmaking para programadores. Desliza entre perfiles basados en stacks tecnológicos, conecta con colegas que dominen tus mismos lenguajes y encuentra a tu socio ideal para el próximo gran proyecto o hackathon. Y lo que surja.

## Tecnologias utilizadas

- Lenguaje: Java (Programación Orientada a Objetos: clases, herencia, polimorfismo, manejo de excepciones).

- Base de datos: Mariadb, acceso mediante JDBC, Dbeaver o mariadb

- Ficheros: XML para exportación de datos e informes, consultas mediante XPath.

- Control de versiones: Git y GitHub (uso obligatorio para el desarrollo del proyecto).

## Funcionamiento

- Necesario tener el Framework Spring-Boot corriendo, El docker o maquina virtual con la database coriendo.
